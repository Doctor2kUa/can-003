AWS SAA-C03 Offline Quiz для Mac

Как пользоваться:
1. Распакуйте ZIP.
2. Откройте файл aws_saa_c03_offline_quiz.html двойным кликом.
3. Проходите вопросы в Safari, Chrome или Firefox.
4. Статистика сохраняется локально в браузере через localStorage.

Важно:
- В квиз включены 642 вопросов, для которых найден правильный ответ.
- 42 вопросов без ответа вынесены в questions_without_answers.csv.
- Интернет и сервер не нужны.
- Если открыть файл в другом браузере, статистика будет отдельная.
- Для переноса статистики используйте кнопку "Экспорт статистики CSV".

Горячие клавиши:
A/B/C/D/E — выбрать вариант.
Enter — ответить или перейти дальше.
